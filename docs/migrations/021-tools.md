# 021 — 主动道具

规则边界为 `tools.hpp/.cpp`，来源是 upstream 的 `rich4_tool_*.asm`、`rich4_tool_utils.c`、`rich4_objects.asm` 和 `rich4_ui_use_tool.asm`。当前已迁移主动效果与消费边界，原 AI 的完整道具选择策略仍需独立接入验证。

## 行为

- 机车和汽车替换旧交通时归还旧物品到玩家库存，设置二/三颗骰子。装备时只减玩家库存，不归还共享供应，重复装备同类型无效。
- 工程车保存原交通和骰数到原 +100/+101 字段，再设置交通 `0x1f`、一颗骰子。持续回合和道路拆除由 Session 处理。
- 路障、地雷、定时炸弹使用原对象槽 16–25、26–35、36–45（零基），在道路标志写入一基对象 ID。库存仅在实际放置成功后减少；移除时才归还共享库存。拒绝重复占据道路及越界对象。
- 机器娃娃、遥控骰子、时光机、机器工人和两种飞弹通过明确回调串接 Session 的移动、历史快照、升级和区域作用。必需回调缺失时返回 unsupported，不能扣除道具后跳过。
- 遥控骰子只接受 1–6。时光机仅在恢复成功后消费恢复状态中当前玩家的道具；无可恢复回合时保持库存。
- 传送机保留原两步选择：地产可搬到同类无人拥有、未建设空地，转移所有者、等级、类型与租期；人物/特殊人物和对象移到道路，更新占据标志、朝向、上一节点和附身对象位置。人物的朝向按目的地可用邻居与原朝向的最小八方向差选择，并保持原邻居顺序处理并列。
- 道具选择标志以 `selection_flags()` 暴露，使用原实例编码，允许 Session 与卡片共用选择器。可见范围与鼠标选择的过滤由 Session/地图投影处理，不由效果函数重新猜测。

返回值分开表示支持、实际生效和原因。取消、不持有、无可用对象槽、无道路邻居等均不消费库存。游戏核心不调用 SDL、不包含 Win32 结构或机器码。

## 验证

`tools_tests` 覆盖换车和归还、重复装备拒绝、工程车保存原状态、道路占据冲突、各类对象槽与库存保留、地产搬迁、人物与附身对象同步移动、无回调和取消不消费、指定骰子边界、时光机恢复失败。

当前测试为 C++20 合成场景，严格 `-Wconversion -Wsign-conversion -Werror` 编译，及 ASan/UBSan 执行。尚未生成道具完整原 EXE 操作差分，不把消费单测当作 AI、碰撞、神明附身或时光机完整回放的验收证据。
