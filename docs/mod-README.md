# 大富翁4 MOD 分支

此分支在原版重構 `main` 之上獨立開發。**不合併回原版**，不更動原版玩法的限制。

## 規則差異

| 規則 | 原版 `main` | `mod` |
| --- | ---: | ---: |
| 股票報價上限 | 9,999 | **999,999** |
| 每種類道具最多持有 | 9 | **999** |
| 新遊戲「總資金」 | 10,000 至 300,000 六檔 | 原六檔之外新增 **30,000,000** |
| 物價指數 | 按資產成長可提高 | **始終 1**（含讀取舊存檔） |

遊戲原始資料的價格上下界、股票日變動、紅卡/黑卡、股票漲跌停計算
改為使用新的報價上界；UI 顯示仍使用帶千分位分隔的整數。
30,000,000 是新遊戲「總資金」而非每位玩家額外的現金；仍按原來現金/銀行比例分配。

## 強制資料相容檢查

- 原始 DAT 中每人 **15 個道具欄位各為 1 byte**，最多僅能放 255。
  MOD 內存使用 `uint16_t`，存成 DAT 時對超過 255 的欄位存儲 255，
  真實數量另記在同名的 **`.DAT.mod`**，版本標記 `RICH4-MOD-TOOLS-1`。
  該檔案記錄 DAT 長度、FNV-1a 64-bit 校驗和、玩家數及所有 15 欄
  實際數量（0–999）；讀取時先**驗證全部內容**才改動內存。
- 讀取原版 DAT 沒有 `.mod` 時依照原本字節數量載入；一旦 MOD 保存，
  兩個檔案必須**一起備份/複製/還原**。若附屬檔丟失，超過 255 的數量
  只可從 DAT 回復成 255，無法憑空找回。
- 股票高價交易會事先拒絕超過 32-bit 資金餘額或 16-bit 供應量的
  購買/賣出，避免負餘額、股數回捲或在修改途中失敗。
  過大的資產估值在既有 int32 接口中飽和到 `INT32_MAX`，
  不會以負資產展示；這也意味著超過此值的精確財富並不在
  原 DAT 格式中表達。
- 一次賣出 999 道具得到的點券最多飽和到 65535（原版點券是 16-bit），
  不會從 65535 回捲成零；共用道具供應量仍受原版 8-bit 數量限制。
- 時光機回溯與每月資產統計均不應提高物價指數。
- Android MOD 的 `applicationId` 為 `io.divby0.rich4.mod`，
  應用名「大富翁4 MOD」；可與 `io.divby0.rich4` 的原版同時安裝，
  但**兩個獨立應用的存檔也完全分開**。

## 測試與局限

- 原版完整 36 項核心測試 + MOD 999 道具、999999 股價、超限
  交易拒絕、背包附檔污染/損壞校驗、讀檔物價指數測試。
- 股票報價與持股數相乘可超過 INT32_MAX；此 MOD **沒有**
  把原始存檔所有資產、銀行、股票成本欄位改為 64-bit。
  因此極高單筆買賣被拒絕，不代表可以無限額交易。
- MOD 簽名與原版是不同的安卓套件；如果想在未來對 MOD APK
  直接覆蓋安裝，需在 CI 使用**同一把**保留的私人測試簽名密鑰。
  工作流已支援 GitHub 加密 Secrets `RICH4_KEYSTORE_B64`、
  `RICH4_KEYSTORE_PASSWORD`；未設定時每次仍產生臨時測試證書。
